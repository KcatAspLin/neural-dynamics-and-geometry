# Computational companion: Neural Dynamics and Geometry

Nine runnable Python tutorials accompany *Mathematical Foundations of Neural Dynamics and Geometry*. The archive includes scripts, shared helpers, generated figures, recorded numerical results, saved arrays, and a trained delayed-memory RNN checkpoint.

Run commands from the directory containing `code/`, `results/`, and `figures/`.

## Setup and execution

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r code/requirements.txt
python code/run_all.py --seed 17
```

The recorded environment uses Python 3.12.14 and Linux CPU PyTorch. To reproduce the tested package versions:

```bash
python -m pip install -r code/requirements-tested.txt --extra-index-url https://download.pytorch.org/whl/cpu
```

On another platform, use its supported PyTorch wheel rather than the Linux `+cpu` build. The broad ranges in `requirements.txt` are compatibility guidance; only the exact recorded environment was executed. A GPU is not required.

To keep the delivered results and figures intact, choose new output directories:

```bash
python code/run_all.py --seed 18 --out new_results --figures new_figures
```

To run one tutorial:

```bash
python code/07_neural_persistence.py --seed 17 --out my_results --figures my_figures
```

`run_all.py` executes the nine scripts sequentially, uses one numerical-library thread, and stops on an error. The first UMAP run can spend extra time compiling numerical kernels. Each numbered script sets its own seed and can be run directly with the bundled shared helpers present. Results may vary across package versions and platforms.

## Tutorial map

| Script | Topic |
|---|---|
| `01_pca_dimension.py` | Intrinsic, linear, effective, and estimated dimension |
| `02_embedding_comparison.py` | PCA, Isomap, and UMAP on a Swiss roll with known intrinsic distances |
| `03_phase_portraits.py` | Sinks, oscillations, competing basins, and numerical integration |
| `04_fixed_points.py` | Fixed-point search and Jacobian stability |
| `05_ring_attractor.py` | Radial relaxation and persistent phase displacement |
| `06_manifold_clouds.py` | Persistence of circle, sphere, torus, and disk clouds |
| `07_neural_persistence.py` | Synthetic neural topology with a specified statistical null |
| `08_trained_rnn.py` | Training and analyzing a delayed-memory recurrent network |
| `09_competing_dynamics.py` | Matching observational trajectories and discriminating interventions |

`recurrent_tools.py` supplies full-state Jacobians for RNN, GRU, and LSTM cells. The trained example is a tanh RNN; LSTM analysis uses both hidden and cell state.

## Outputs and interpretation

Numbered JSON files record metrics, seeds, and software versions. NPZ files preserve the main arrays and persistence diagrams. Figures are supplied as vector PDF and PNG. The checkpoint stores model/readout weights, optimizer state, random-number states, and training metadata. It was generated by this project. Loading the complete PyTorch optimizer/RNG payload may require `weights_only=False`; only use that option for a trusted checkpoint. The provided NumPy arrays support read-only analysis without loading the checkpoint.

Read `VALIDATION.md` for the numerical results and limits. The examples are synthetic and educational. A persistent loop does not establish an attractor, a near-zero eigenvalue in a finite ring network does not prove exact continuous symmetry, and a successful null rejection does not identify a unique biological mechanism.
